# Changelog

## 1.0.0 (2026-11-27)

First public version of the audit, with measurements from 2026-11-25 UTC.

- Inference API benchmarks: smoke, error contract, latency (plain, grounded, vendor route, prompt
  size), grounding, caches, tools and streaming.
- Tasks API benchmarks: accuracy ladder, cost and time caps, cancel, idempotency, files and request
  validation.
- Findings: INF-A1 to INF-A6, TSK-A1 to TSK-A6 and portal notes.
- Redacted call logs, processed summaries and the offline scripts that recompute them.
- Docs: architecture and a code reference generated from the docstrings.
